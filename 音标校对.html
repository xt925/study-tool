批量音标校对台

导入 OCR 词表 → 批量查询参考音标 → 审查差异 → 回写原始 JS / 导出 JSON、CSV。

① 导入数据

支持你现有的 JS 词表对象（例如 const words_7a = { units: [...] }），也支持 JSON、CSV。JS 导入会尽量保留原格式，导出时只回写音标字段。

数据默认只保存在当前页面；可手动导出备份。

② 查询与校对

说明：「离线 IPA 词典」用的是开源词库 ipa-dict（英式 6.5 万词 / 美式 12.6 万词），第一次查询时下载一次（英式约 1.7 MB，浏览器会缓存），之后批量查询完全离线，不受限流影响。原来的 Free Dictionary API 目前服务端大量返回 522，已降为备用。参考音标只是候选项，不会自动覆盖原音标；多音词、短语请人工确认。「词典发音」用的是有道发音直链，仅供试听。
#英文释义原音标（可编辑）参考音标词典发音状态 / 操作
请先导入词表。

③ 导出校对结果

回写 JS 会保留原始数据结构、释义等字段，并替换或补齐每条单词记录中的 phonetic。建议导出后先做代码 diff，再替换项目原文件。

校对工具不能保证参考音标一定正确。请特别复核多音词（如 wind）、词性依赖读音的词，以及 API 未返回结果的短语。不要把“参考音标不同”直接等同于“原音标错误”。
