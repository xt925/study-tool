# 跟读打分（腾讯云口语评测）对接与密钥配置

> 最后更新：2026-09-28
>
> 本文记录「跟读打分」功能的完整对接方式、密钥怎么配、出问题怎么查。换电脑或过段时间要改这块时，看这一篇就够了。

## 一、这个功能是什么

游戏乐园 → **🎤 跟读打分**（路由 `/games/speech`）。

流程：听一遍标准发音 → 点按钮录音跟读 → 上传音频到腾讯云评测 → 返回总分和「准确度 / 流利度 / 完整度」，并把读得不准的音素（如 `/θ/`）标出来。分数 ≥80 加 10 星，≥60 加 5 星。

## 二、整体架构（为什么要这么设计）

```
H5（浏览器/WebView）                    你的阿里云服务器                    腾讯云
─────────────────────                ────────────────────              ─────────────
1. 录音，转 16k PCM
2. POST /api/speech/token  ─────────►  用 SecretKey 算签名
   （带登录 token）                      返回签名后的 WSS 地址  ──────►
3. 直连 WSS，推流音频  ────────────────────────────────────────────►  SOE 引擎评测
4. 拿回分数渲染         ◄──────────────────────────────────────────  PronAccuracy 等
```

关键点：**腾讯的 SecretKey 只存在服务端**，前端拿到的只是「已签名的、5 分钟内有效的 WSS 地址」。所以音频不经过你的服务器，SecretKey 也不会泄露到浏览器。

所以有两个前提：**必须先登录**（接口走 `requireAuth`，防止密钥被白嫖），以及服务器要能访问外网（推流是前端直连腾讯，服务器只做签名，这点没额外要求）。

## 三、开通与拿密钥（从零开始）

1. **实名认证**腾讯云账号（没实名拿不到密钥也没法用套餐）。
2. **开通「智聆口语评测（新版）」服务**：控制台搜索「口语评测」，或直接进 [开通页](https://console.cloud.tencent.com/soenew)。
   - ⚠️ 一定要选**新版**。旧的「口语评测（基础版）」只对老用户开放，新用户用不了。
   - 购买页：https://buy.cloud.tencent.com/soenew
3. **拿密钥**：访问管理 → [API 密钥管理](https://console.cloud.tencent.com/cam/capi)，新建密钥，得到三个值（**只显示一次，务必存好**）：
   - **AppID**：控制台账号信息里那个数字 AppID，不是密钥本身
   - **SecretId**
   - **SecretKey**
   - 用子账号的密钥也可以，但要给该子账号授权口语评测相关权限；图省事就用主账号密钥。
4. 确认套餐包次数（买过的那个 1 万次/年，扣完可以续购）。

## 四、配置密钥

服务端读 4 个环境变量：

| 变量 | 必填 | 说明 |
|------|------|------|
| `SOE_APP_ID` | 是 | 腾讯云账号 AppID |
| `SOE_SECRET_ID` | 是 | SecretId |
| `SOE_SECRET_KEY` | 是 | SecretKey，**绝不能进前端和 git** |
| `SOE_SCORE_COEFF` | 否 | 打分苛刻度，范围 `1.0–4.0`，不填默认 `1.5` |

### 本地开发

在 `apps/server/` 下新建 `.env`（该文件已加进 `apps/server/.gitignore`，不会被提交）：

```bash
SOE_APP_ID=你的AppID
SOE_SECRET_ID=你的SecretId
SOE_SECRET_KEY=你的SecretKey
SOE_SCORE_COEFF=1.5
```

Node 22 启动时会自动加载（代码里用的是内置的 `process.loadEnvFile`，没有引入 dotenv）。然后在仓库根目录跑：

```bash
npm run dev --workspace apps/server
```

### 线上（阿里云 pm2）

在服务器上建 `/var/www/english-study-server/apps/server/.env`，内容同上，然后：

```bash
pm2 restart english-study-server
```

代码会依次尝试这两个位置的 `.env`，所以放 monorepo 根目录也行：
- `当前工作目录/.env`
- `apps/server/.env`（相对服务端代码位置）

**两个坑**：
- `process.loadEnvFile` **不会覆盖已存在的环境变量**。如果 pm2 里已经设过同名变量，以 pm2 的为准——那种情况就干脆配在 pm2 的环境变量里，别放 `.env`。
- 改完 `apps/server` 的代码要按 CI 规则部署（手动触发 workflow 或打 tag）才会生效；只改服务器上的 `.env` 则 `pm2 restart` 即可。

### 关于 `SOE_SCORE_COEFF`（苛刻度）

腾讯用它来平滑不同年龄段的分数，**值越大打分越严**：

| 值 | 大致对应 |
|----|----------|
| 1.0 | 最小年龄段，儿童场景，最宽松 |
| 1.5 | 当前默认，给初中生用 |
| 2.0–3.0 | 青少年偏严格 |
| 4.0 | 成人严格打分 |

觉得外甥分数偏低就调小，偏高就调大。改完要重启服务端。

## 五、怎么验证配好了

**第一步**：不登录直接请求，应该返回 401：

```bash
curl -s -w '\n%{http_code}\n' -X POST http://127.0.0.1:3000/api/speech/token \
  -H 'Content-Type: application/json' -d '{"text":"apple","mode":"word"}'
```

**第二步**：登录后请求，应该返回 200 和一条 `wss://soe.cloud.tencent.com/...` 地址：

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:3000/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"你的账号","password":"你的密码"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['token'])")

curl -s -X POST http://127.0.0.1:3000/api/speech/token \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"text":"apple","mode":"word"}'
```

如果没配密钥，会返回 503 并明确告诉你缺哪个变量：

```json
{"error":"服务端未配置口语评测密钥（SOE_APP_ID / SOE_SECRET_ID / SOE_SECRET_KEY）"}
```

**第三步**：手机上打开 `/games/speech`，真的读一遍，能看到分数就通了。这一步才是真正的端到端验证。

## 六、代码在哪

| 文件 | 作用 |
|------|------|
| `apps/server/src/soe.ts` | 签名算法 + 连接 URL 拼装，读环境变量 |
| `apps/server/src/index.ts` | `POST /api/speech/token`（需登录）；启动时加载 `.env` |
| `apps/h5/src/utils/speech.ts` | 录音 → 转 16k PCM → WSS 推流 → 解析分数 |
| `apps/h5/src/views/SpeechGame.vue` | 跟读打分页面 |
| `apps/h5/src/utils/api.ts` | `getSpeechToken()` |
| `apps/h5/src/router/index.ts`、`views/GamesView.vue` | 路由与游戏列表入口 |

### 关键参数（都写在 `soe.ts` 里）

| 参数 | 值 | 说明 |
|------|-----|------|
| `server_engine_type` | `16k_en` | 英文引擎 |
| `voice_format` | `0` | PCM 裸流 |
| `eval_mode` | `0` / `1` | 单词模式 / 句子模式（默认单词） |
| `rec_mode` | `1` | 录音模式：一次性发完整段音频，不用按 1:1 实时率推流 |
| `score_coeff` | 1.5 | 见上文苛刻度 |
| 签名有效期 | 300 秒 | 只够建立连接，避免地址被复用到别处 |

音频要求：**16000Hz / 16bit / 单声道**。前端用 `MediaRecorder` 录音，再用 `OfflineAudioContext` 重采样成 16k，不用手动写重采样算法。

### 计费口径

- **一个单词或一句话算 1 次调用**，扣腾讯云套餐包次数。
- 单词/句子模式下每条请求算 1 次；只有「段落模式/自由说模式」才按每 20 词折算。
- 当前只用了单词模式。

## 七、排错

| 现象 / 错误 | 原因 | 怎么办 |
|---|---|---|
| 接口返回 503，提示未配置密钥 | 环境变量没读到 | 检查 `.env` 路径和变量名；pm2 里是否已有同名变量 |
| 接口返回 401 | 没登录或 token 过期 | 先登录 |
| 页面提示「评测鉴权失败」（code 4002） | SecretId/SecretKey 不对 | 重新核对密钥 |
| 页面提示「评测次数已用完」（code 4004） | 套餐包耗尽 | 去腾讯云控制台续购，或开通后付费 |
| 页面提示「当前评测并发超限」（code 4006） | 单账号默认 50 路并发 | 正常个人使用不会遇到，稍后重试 |
| 页面提示「没有听到声音」（code 4105/4108） | 没录到人声 / 音量太小 | 靠近麦克风、读大声点 |
| 页面提示「文本太长了」（code 4104） | ref_text 超字数 | 句子模式不超过 30 词、段落模式不超过 120 词 |
| 点录音没反应 | 非 HTTPS 或没有麦克风权限 | 必须 HTTPS（localhost 例外）；APK 里 WebView 可能还需 uni 侧放行录音权限 |
| 页面提示「连接评测服务失败」 | 网络到 `soe.cloud.tencent.com` 不通 | 检查设备网络（这个连接是前端直连腾讯的） |

> 注：错误码含义见 [腾讯云官方文档](https://cloud.tencent.com/document/product/1774/107497)，`speech.ts` 里对常见几个做了中文提示转换。

## 八、想扩展的时候

- **整句跟读**：参数已打通，调用时传 `mode: 'sentence'` 即可（`eval_mode=1`），注意句子不超过 30 个单词。
- **想放开登录限制**：去掉 `apps/server/src/index.ts` 里 `/api/speech/token` 的 `{ preHandler: requireAuth }`。**不建议**，会让密钥被白嫖。
- **想换回讯飞**：签名逻辑集中在 `soe.ts`，前端只需要改 `speech.ts` 里拿地址和推流的部分。
