# 数据库命令记录

服务端使用 SQLite（better-sqlite3）。数据库文件路径由环境变量 `DB_PATH` 决定，默认为服务启动目录下的 `./data/app.db`。
```bash
cd /var/www/english-study-server/apps/server
```

以下命令默认在服务运行目录下执行。

## 账号与权限

### 查看所有账号

```bash
sqlite3 data/app.db "SELECT id, username, role FROM users;"
```

### 将账号设为管理员

`users` 表的 `role` 字段控制权限，默认 `'user'`，管理员为 `'admin'`。

```bash
sqlite3 data/app.db "UPDATE users SET role='admin' WHERE username='用户名';"
```

说明：

- 不用重启服务、也不用重新登录：每次请求都会用 token 联表查询 `users.role`，改完立即生效。
- 前端如果缓存了登录时返回的 `role`，界面上的管理员入口可能要重新登录才显示。

### 没有 sqlite3 命令行时的替代写法

```bash
node -e "const db=require('better-sqlite3')('data/app.db');db.prepare(\"UPDATE users SET role='admin' WHERE username=?\").run('用户名')"
```
