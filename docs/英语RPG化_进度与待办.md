# 英语 RPG 化 —— 进度与待办

> 最后更新：2026-10-23。记录「把英语学习做成轻 RPG」这一轮需求的完成情况、设计口径和后续待办。
> 相关代码：`packages/core/src/utils/chapters.ts`、`apps/h5/src/views/AdventureView.vue`

## 一、需求背景

目标不是加一层游戏皮肤，而是让**英语掌握度决定游戏进度**：

- 学新词、复习、听力、综合挑战 → 推进地图上的章节
- 只答简单题、反复刷小游戏 → 不能推进核心内容
- 不做抽卡数值、复杂战斗、开放世界，先跑通最小闭环

关键判断（本轮已按此落地）：

1. 推进资源不能是「可积累、可消费的第二种货币」，否则一定被刷。知识印记改成**从复习数据推导的不可花徽记**。
2. 星星继续做软通货（宠物、服装），刷了只影响外观，不影响地图。
3. 地图节点状态**不落库**，全部实时推导，避免「完成标记」被反复利用，也省掉一次数据迁移。

## 二、已完成（最小闭环第一期）

### 1. 章节地图

- 章节 = 教材 Unit（按 7a~9b 全册自动生成，无需手写关卡）
- 每章四个节点：📖 认识新词 / 🔁 复习巩固 / 🎧 听力挑战 / ⚔️ 综合挑战
- 完成条件：

  | 节点 | 条件 |
  |---|---|
  | 认识新词 | 单元词全部学过 |
  | 复习巩固 | 单元内无到期词，且 ≥60% 的词复习答对过 |
  | 听力挑战 | 该单元最好一轮听力正确率 ≥80% |
  | 综合挑战 | ≥60% 的词达到 `MASTERED_STAGE`（stage ≥ 3） |

- 解锁链：认识新词 → 复习巩固 → 听力挑战 → 综合挑战（前置未完成时节点置灰）
- 入口：首页「🗺 冒险地图」卡片（显示当前章节 + 4 节点进度）→ `/adventure`
- 地图页支持分册切换、章节展开/收起、当前章节高亮

### 2. 知识印记

- 口径：`reviewStates` 中 `stage >= 3` 的单词数，每个单词最多产出 1 枚
- 上限 = 词库总量，重复做题不增产
- 首页与地图页展示总数

### 3. 入口联动

- 复习页支持 `?unit=<unitId>`：只复习当前章节的词
- 听音选词支持 `?unit=<unitId>`：直接从章节进入该单元挑战
- 听力成绩写入新字段 `listenResults: Record<unitId, { correct, total, at }>`，只保留该单元最好一轮
- 服务端 `normalizeProgress` 已同步该字段；多设备合并按「答对更多、同分取更新」处理

### 4. 验证

- `npm test`：40 个用例通过（新增章节规则 7 个、听力成绩 2 个）
- `npm run build` / `npm run build:server` 通过
- 浏览器实测：分册切换、章节展开、锁定节点不可点、首页入口与进度条均正常，无控制台报错

## 三、待办（最小闭环剩余部分）

按优先级排列，均不改动已有学习流程，只做增量。

### P0 — 伙伴反馈（学习后的即时回应）

- [ ] 每次学习结束（学完一个单元 / 完成一次复习）时，用**数据差量 + 模板池**生成一句伙伴反馈
- [ ] 差量来源：新增已学词数、清除错题数、延迟复习正确数、本章节点变化
- [ ] 模板池 20~30 条即可，按「增量类型 + 数量档位 + 薄弱词」组合；不接大模型
- [ ] 展示位置：学习完成页 / 首页宠物卡片气泡，仅当日首次展示，避免刷屏

### P1 — 每周章节节奏

- [ ] 周目标模板：周一~周二探索新词、周三听力、周四清错题、周五综合挑战、周末自由
- [ ] 只按「本周累计进度」判断是否推进，不要求每天完成全部任务
- [ ] 不做断签惩罚，中断几天可直接继续

### P1 — 学习效果指标

- [ ] 家长周报增加「延迟复习正确率」（到期 ≥3 天后答对的占比）
- [ ] 增加「初学到稳定掌握转化率」（已学词中达到 `MASTERED_STAGE` 的比例）
- [ ] 后续再考虑「每次学习的有效时长」，区分学习与刷奖励

### P2 — 体验打磨与调参

- [ ] 分册切换行加滚动提示（当前首屏第 4 个标签会被裁切）
- [ ] 真实试玩后校准 `REVIEW_SHARE` / `MASTERY_SHARE` / `LISTEN_PASS_RATE`（当前 60% / 60% / 80%）
- [ ] 视情况把「当前章节」与所选分册联动，或在切换分册时提示全局下一站

## 四、待考虑事项（不是不做，暂不排期）

### 地图与叙事

- 地图动画、区域动效
- 主线剧情文本、角色对话剧情
- 月度成长阶段与「学习纪念物」展示（优先用现成数据生成回顾卡，不再建一套资产体系）

### 伙伴与收集

- 多伙伴收集（现有宠物系统已具备切换基础，但先不做抽卡/战力）
- 伙伴稀有度、抽卡概率

### 抽卡（重点待考虑）

用户明确认为抽卡有上瘾风险，但也可以被正向利用；不限定为抽人物/宠物。可考虑的形态：

- **抽单词**：把「复习到期词」「错题」包装成卡池，抽到即进入一次针对性练习
- **单词 + 装备/技能结合**：某个词掌握度达标后变成一件道具/技能，用于解锁章节或小玩法
- **只给外观与收集**：伙伴皮肤、装扮、图鉴，不绑定战力
- **硬性约束（若要做）**：不做付费、不做概率暗箱、不因抽卡损失既有进度；抽卡结果不替代学习行为，只作为学习后的奖励层

### 数值与战斗

- 装备强化、属性数值、战斗强度
- 实时对战、开放世界

## 五、已知取舍

- 章节节点不持久化：每次进入按当前时间重新判断，到期的复习会让已完成的复习节点重新变为未完成（符合「掌握会遗忘」的设计，但孩子可能觉得「怎么又退回去了」，试玩后决定是否加提示文案）
- 综合挑战按钮进入的是单元测验，但节点完成只看掌握度，不看测验成绩；按钮文案已改为「掌握 x/y 个才点亮」以降低误解
- 星星仍可被反复玩小游戏刷取，这是有意保留的：它只影响宠物与装扮，不影响地图推进
