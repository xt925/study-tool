# 音标字符表（DJ 音标 / 英式 IPA)

初中英语课本使用的音标字符全集，电脑和手机都能正常显示。校正音标时直接复制下表中的字符即可。

## 单元音（12 个）

| 长音 | 短音 |
| ---- | ---- |
| iː | ɪ |
| ɜː | ə |
| ɑː | ʌ |
| ɔː | ɒ |
| uː | ʊ |
|    | e |
|    | æ |

## 双元音（8 个）

```
eɪ   aɪ   ɔɪ   əʊ   aʊ   ɪə   eə   ʊə
```

## 辅音（28 个）

```
p  b  t  d  k  g            爆破音
f  v  θ  ð  s  z  ʃ  ʒ  h   摩擦音
tʃ  dʒ  tr  dr  ts  dz      破擦音
m  n  ŋ                     鼻音
l  r  j  w                  其他
```

## 附加符号（2 个）

```
ˈ   主重音，标在重读音节前，如 /səˈpəʊz/
ˌ   次重音，如 /ˌɪmpəˈtɪəns/
```

## 识图复制时最容易丢的字符

微信图片识别复制时，下面这类特殊字符经常丢失或变成形近字母，校对时重点检查：

```
ə  ɔ  æ  ɒ  ʊ  ʌ  ɪ  θ  ð  ʃ  ʒ  ŋ  ˈ  ˌ  ː
```

典型错误对照：

| 单词 | 错误（识图结果） | 正确 |
| ---- | ---------------- | ---- |
| suppose | /sa'pauz/ | /səˈpəʊz/ |
| strawberry | /'stro:bari/ | /ˈstrɔːbəri/ |
| birthmark | /bs:θma:k/ | /ˈbɜːθmɑːk/ |

## Windows 输入这些字符的方法

1. `Win + .` 打开表情面板 → 符号 → 拉丁字母（部分字符有）
2. 直接从本表复制（最省事）
3. 装一个支持 Unicode 输入的输入法
